🏦 Novo Layout Extrato Banco do Brasil v2026

Documentação de Referência Visual e Técnica

📋 Visão Geral

O Banco do Brasil atualizou o layout de seus extratos a partir de 2026. O novo formato apresenta uma tabela estruturada com colunas bem definidas, facilitando a leitura por humanos e máquinas.

✓ Status do Parser: Implementado e testado com 10/10 testes passando

📊 Estrutura Tabular

O layout é organizado em 5 colunas principais:

Dia

Data da operação no formato DD/MM/YYYY

Ex: 04/05/2026

Lote

Identificador do lote (4-5 dígitos numéricos)

Ex: 14397, 13105

Documento

ID único da transação (12+ dígitos)

Ex: 10903125172831

Histórico

Descrição completa com data/hora, CPF/CNPJ e nome

Ex: Pix - Recebido 01/05 09:03 55802389168 JOSE ANTONIO

Valor

Montante com tipo ((+) crédito ou (-) débito)

Ex: 500,00 (+) ou 2.458,92 (-)

⚙️ API do Parser TypeScript

Função: parseBbExtratoV2026Line()

Faz parse de uma única linha de transação.

import { parseBbExtratoV2026Line } from './bbExtratoV2026Parser'; const line = '04/05/2026 14397 10903125172831 Pix - Recebido 01/05 09:03 55802389168 JOSE ANTONIO D 500,00 (+)'; const result = parseBbExtratoV2026Line(line); if (result) { console.log(result.data); // "04/05/2026" console.log(result.valor); // 50000 (em centavos) console.log(result.tipo); // "credito" console.log(result.historico); // "Pix - Recebido..." }

Função: parseBbExtratoV2026Text()

Faz parse de múltiplas linhas.

import { parseBbExtratoV2026Text } from './bbExtratoV2026Parser'; const text = ` 04/05/2026 14397 10903125172831 Pix - Recebido 01/05 09:03 55802389168 JOSE ANTONIO D 500,00 (+) 04/05/2026 13105 50401 Pagamento de Boleto GUABI NUTRICAO S ANIMAL LTDA 2.458,92 (-) `; const rows = parseBbExtratoV2026Text(text); rows.forEach(row => { console.log(`${row.data} - R$ ${(row.valor / 100).toFixed(2)}`); });

🛡️ Mascaramento de Dados Sensíveis

Para proteger informações confidenciais, dois scripts de mascaramento foram fornecidos:

  • Python: scripts/mask-bb-extrato-pdf.py
  • Node.js: scripts/mask-bb-extrato-pdf.mjs

Uso do Script Python:

python scripts/mask-bb-extrato-pdf.py extrato.pdf extrato-mascarado.pdf

Uso do Script Node.js:

node scripts/mask-bb-extrato-pdf.mjs extrato.pdf extrato-mascarado.pdf

ℹ️ Nota: O mascaramento cobre:

  • Informações de cliente (cabeçalho)
  • Linhas de transação (dados sensíveis)
  • Saldos e totalizadores (rodapé)
